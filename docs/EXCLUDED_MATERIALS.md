# Excluded source material

The following supplied materials were intentionally not copied into this repository:

| Material | Reason |
| --- | --- |
| Keysight user and service guides | Third-party copyrighted manufacturer documentation; cite or link to the official source instead of redistributing it. |
| Leak-valve hardware and software guides | Third-party documentation; one supplied file also contains an equipment password. |
| Full chamber SOP and annotated operator instructions | Internal laboratory procedure with equipment configuration, network details, and material that predates this project. |
| Personal project-context notes | Contain biographical information and informal statements that are not needed for a technical portfolio. |
| Raw Word bug register | Replaced by the concise English record in `docs/BUG_HISTORY.md`. |

These exclusions protect credentials, institutional information, copyright, and professional presentation. They do not indicate that the files are unimportant to laboratory operation; they should remain in the controlled laboratory document store.
