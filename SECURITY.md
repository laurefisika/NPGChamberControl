# Security policy

This project controls laboratory equipment and should be handled as safety-relevant research software.

Do not report equipment passwords, internal network addresses, unpublished sample data, or personal information in a public GitHub issue. Use the laboratory's approved private communication channel.

Before sharing a diagnostic log, remove sample names, computer names, serial numbers, IP addresses, local paths, saved automation modes, and experimental results that have not been approved for release.

The software is not a safety PLC and does not replace hardware interlocks or operator supervision. Suspected unsafe behavior should result in suspension of experimental use until the laboratory owner has reviewed it.
